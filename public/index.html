4 · Layer control · cue list

Cues run like in QLab. A trigger fires a cue: a Mukana event (while Auto layers is on), or GO here or from Companion. After its pre-wait the cue does its action. Auto-continue starts the next cue at the same moment as this one, so the pre-waits of a run of auto-continued cues read like a timeline (0 s, 3 s, 6 s…); auto-follow starts the next cue when this one is done. A cue fired again restarts and stops what it started; Cancels stops other cues (numbers, e.g. 2, 3). Question text is written before a layer goes live and cleared only after it has gone off.
